# Blush
A premium, 3D-interactive web experience for Blush Beauty Parlour featuring Three.js, GSAP animations, and a responsive modern UI.

Blush Beauty Parlour | Premium 3D Experience
A high-end, immersive web application designed for Blush Beauty Parlour. This project combines luxury aesthetics with cutting-edge web technologies to provide a safe and empowering digital space for women.  

✨ Key Features
-> Immersive 3D Graphics: Built with Three.js, featuring an interactive gem-entry system and dynamic background particles.  
-> Smooth Motion Design: Integrated GSAP (GreenSock) for high-performance transitions and scroll-based animations.  
-> Modern UI/UX: A responsive, mobile-first design utilizing custom CSS variables and glassmorphism effects.  
-> Service Showcase: Interactive cards detailing treatments like Skin Therapy, Wellness Rituals, and Hair Treatments.  
-> Direct Booking: Integrated WhatsApp and Click-to-Call functionality for seamless client appointments.  

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Custom Properties), JavaScript (ES6+)  
Graphics: Three.js
Animation: GSAP
Fonts: Playfair Display & Quattrocento Sans via Google Fonts
